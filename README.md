## How it works

`main.ts` (Node 22, standard library only) copies `entry.png` — the finished
1024×1024 front page — to the output directory as `entry.png`. It runs with no
network and writes identical bytes on every run.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
